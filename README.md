# فُسحة

نموذج أولي مستقل للعبة استراحة مرحة باللغة العربية، مبني بـ HTML وCSS وJavaScript دون حزم أو أطر عمل.

المشهد الأساسي مرسوم عبر WebGL 1.0: أرضية بمنظور كاميرا، وإضاءة مجسّمة وديكور وشخصيات مركبة من أسطح ثلاثية الأبعاد إجرائية. لكل موقع تكوينه المرئي الخاص: أشجار وفطر وزهور في الحديقة، وسحب وجزيرة عائمة ونجوم في جزيرة الغيم، وحامل لوحة ولوحة وألوان في ورشة الرسم. الأشعة من الكاميرا تحدد الجزء الذي لمسه المؤشر، بينما تتغير المفاصل والوجه والملابس والإكسسوارات مع التفاعل. حركة السقوط تستخدم الجاذبية وارتدادًا خفيفًا وتغيّرًا في زاوية الجذع والرأس، ثم تتكئ الشخصية على أطراف مختلفة وتحاول النهوض على مراحل. يزامن الارتطام أثر موجة على الأرض واهتزازًا وجيزًا للكاميرا مع صوت الاصطدام والغبار. ردود الفعل في المشهد حركية وصوتية بلا فقاعات كلام أو ملصقات؛ تُولّد أصوات الشخصية غير اللفظية محليًا عبر مرشحات Web Audio، وتُزامن فتحة الفم معها، مع أصوات احتكاك وارتطام وغبار ثلاثي الأبعاد. الحركة والمجسمات مقصودة بأسلوب كرتوني أصلي، وليست محاكاة بشرية أو نظام هيكل عظمي احترافيًا؛ الارتداد والظل تقريبيان ولا تستخدم الظلال خرائط عتادية. عند عدم توفر WebGL تبقى الرسوم التوضيحية الاحتياطية قابلة للاستخدام. لا تعتمد الصفحة على حزم خارجية أو تسجيلات صوتية.

فُسحة تطبيق ويب تقدمي (PWA) قابل للتثبيت ويخزّن غلاف التطبيق محليًا للعمل دون اتصال بعد فتحه أول مرة عبر HTTPS أو localhost. تُحفظ الشخصية والمشهد والملابس والإكسسوار ومستوى الصوت وإعدادات إمكانية الوصول والابتسامات في تخزين المتصفح المحلي فقط؛ لا توجد تحليلات أو حسابات أو خدمات خارجية. تشمل إعدادات الراحة تقليل الحركة والتباين الأوضح ومستوى الصوت، إلى جانب جلسة تنفّس موجّهة مدتها ٤٠ ثانية دون حبس النفس. يمكن مسح هذه البيانات من إعدادات تخزين الموقع في المتصفح أو بإعادة ضبط التطبيق.

زر «فاجئني» يختار أجواءً منسّقة مختلفة للشخصية والملابس والإكسسوار والموقع، ويعلن التغيير لقارئات الشاشة. لا يغيّر الاختيار إعدادات الصوت أو الراحة.

يمكن لمس أي موضع على الشخصية أو الانزلاق عبرها؛ تتدرج الاستجابة مع مدة الضغط وقوة القلم وسرعة الحركة. لمس كل خدّ أو المسح عليه يحرّك الرأس والخدّ والعين والأذن في الجهة المقابلة، مع تعبير وصوت قصيرين يتنوعان عند التناوب بين الخدين. السحب الأفقي السريع يلف الشخصية في الاتجاه المطابق للسحب؛ وتراكم اللفات يجعلها تتمايل بدوخة كرتونية ثم تستعيد توازنها. الضغط الأطول قد يؤدي إلى تعثر لطيف للأمام أو الخلف أو بشكل مائل؛ ويضيف اتجاه السحب دفعة للجسم، مع اختلاف توقيت مدّ الذراعين وثني الركبتين والقدمين وتأخر الرأس والجذع. تتكئ الشخصية على أطرافها وتحاول الوقوف بحركات غير متماثلة وعلى مراحل. تتبدل تعابير الوجه والحركة والصوت بحسب التفاعل والشخصية المختارة، مع تنفّس ورمشة عين عند السكون، ودعم إعداد «تقليل الحركة» في الجهاز. زر الأصوات يكتم جميع الأصوات المولدة.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادم ملفات ثابتة من مجلد المشروع:

```sh
python -m http.server 8000
```

ثم افتح `http://localhost:8000`. لا يلزم تثبيت اعتمادات. الأصوات غير اللفظية وطبقات الحركة تُنشأ محليًا عبر Web Audio API بعد أول تفاعل للمستخدم.

يتطلب التثبيت والعمل دون اتصال استضافة آمنة عبر HTTPS (أو localhost للتطوير). هذه قاعدة ويب تقدمية، وليست بعدُ حزمة أصلية جاهزة للنشر في متجر التطبيقات؛ يتطلب النشر هناك إعداد غلاف المنصة واختباراته ومواد المتجر وحساب المطوّر ومراجعة متطلباته.
